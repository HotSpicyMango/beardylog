개인정보처리방침

시행일 2026년 8월 29일

비어디로그(이하 “앱”)는 도마뱀 사육 기록을 남기는 앱입니다. 이 방침은 앱이 어떤 정보를 다루는지 설명합니다.

앱은 회원가입이 없고, 개발자가 운영하는 서버도 없습니다. 개체 프로필·식단·몸무게·브리딩 기록과 사진은 모두 사용자의 기기 안에만 저장되며, 개발자는 그 내용을 볼 수 없습니다.

1. 기기에 저장되는 정보

아래 정보는 사용자가 직접 입력한 것으로, 기기 내부 저장소에만 보관됩니다.

  • 개체 정보 — 이름, 종, 모프, 성별, 해칭(입양)일, 사진
  • 관리 기록 — 식단 및 일정, 몸무게, 달력 메모
  • 브리딩 기록 — 메이팅 날짜, 클러치, 산란·해칭 정보
  • 추억공간 — 떠난 날짜, 추억 메모, 사진

2. Google Drive 백업 (선택)

사용자가 설정에서 직접 실행할 때만 동작합니다. 백업하지 않으면 어떤 데이터도 기기 밖으로 나가지 않습니다.

  • 앱은 앱 전용 폴더 권한(drive.appdata)만 요청합니다. 이 권한으로는 사용자의 다른 Google Drive 파일을 조회하거나 수정할 수 없습니다.
  • 백업 파일(기록과 사진을 묶은 ZIP)은 사용자 본인의 Google 계정에만 저장됩니다. 개발자는 이 파일에 접근할 수 없습니다.
  • 백업 삭제는 앱에서 덮어쓰거나, Google 계정 설정의 앱 데이터 관리에서 할 수 있습니다.

3. 앱이 통신하는 곳

  • Google Drive API — 백업과 복원을 실행할 때만 사용합니다.
  • GitHub — 새 버전이 있는지 확인합니다. 개인정보는 전송하지 않습니다.
  • 한국천문연구원 특일 정보 서비스 — 달력에 공휴일을 표시하기 위해 날짜 정보만 요청합니다. 개인정보는 전송하지 않습니다.

4. 사용 통계와 오류 보고

앱의 안정성을 개선하기 위해 Google Firebase의 Analytics와 Crashlytics를 사용합니다. 여기에는 익명 식별자, 기기 모델, OS 버전, 대략적인 지역, 앱 사용 및 오류 정보가 포함됩니다.

사용자가 입력한 기록이나 사진은 전송되지 않습니다. 수집된 정보는 개인을 식별하는 데 사용되지 않으며, 제3자에게 판매하거나 광고에 활용하지 않습니다.

5. 앱이 요구하는 권한

  • 인터넷 — 백업, 업데이트 확인, 공휴일 조회
  • 앱 설치 요청 — 앱 안에서 새 버전을 설치할 때

위치, 연락처, 마이크 권한은 요구하지 않습니다. 사진은 시스템 선택기를 통해 사용자가 고른 파일만 앱으로 들어옵니다.

6. 보관과 삭제

기기의 기록은 앱을 삭제하면 함께 지워집니다. Google Drive에 올린 백업은 앱 삭제와 무관하게 남으므로, 필요하면 Google 계정 설정에서 따로 삭제해 주세요.

앱은 별도의 계정이나 개인정보를 수집하지 않지만, 만 14세 미만은 보호자의 동의 아래 이용하시기 바랍니다.
