C-03

Drive 백업이 모든 사진을 하나의 JSON 문자열로 메모리에 쌓습니다

ProfileBackupManager.kt:41–51 · ProfileBackupManager.kt:53–66

증상
사진이 많은 사용자가 백업 또는 복원을 누르면 OutOfMemoryError로 종료됩니다. 실패해도 원인을 알 수 없어 "백업이 안 된다"로만 보고됩니다.
원인
모든 사진 바이트 → Base64 문자열(용량 ×1.33) → JSONObject → toString() → toByteArray()가 순차적으로 만들어지며 전부 동시에 힙에 존재합니다. 원본 사진 총량의 3~4배가 한꺼번에 필요합니다. 사진 30장(90MB)이면 이미 300MB 이상이고, 일반적인 앱 힙 상한(256~512MB)을 넘습니다. 복원 경로도 동일하게 응답 전체를 ByteArray → String → JSONObject로 부풀립니다.
개선
구조를 바꾸는 일이라 C-01의 사진 축소가 선행되면 위험이 크게 줄어듭니다. 근본 해결은 두 방향 중 하나입니다.
① ZIP 컨테이너로 전환 — manifest.json(DB 레코드만) + 사진은 원본 바이트 그대로 엔트리로. ZipOutputStream을 파일에 직접 흘려보내므로 메모리에 남는 건 버퍼뿐입니다. Base64 오버헤드도 사라져 업로드 용량이 25% 줄어듭니다.
② 지금 형식을 유지한다면 최소한 JsonWriter로 OutputStream에 직접 스트리밍 기록하고, 업로드는 setChunkedStreamingMode로 바꿉니다.
어느 쪽이든 SCHEMA_VERSION을 올리고, 구버전 백업도 읽을 수 있게 분기해 두세요.

C-06

사진 자르기 전 과정이 메인 스레드에서, 예외 처리 없이 돌아갑니다

SquareCropView.kt:44–56 · CropActivity.kt:51–74

증상
큰 사진을 고르면 크롭 화면이 열릴 때 1~2초 굳고, 저장을 누를 때 한 번 더 굳습니다. 저장 공간이 부족하거나 사진 접근 권한이 만료된 상태면 그대로 앱이 종료됩니다.
원인
SquareCropView.setImage()가 openInputStream().readBytes()로 원본 전체를 읽고 두 번 디코딩하는데 전부 메인 스레드입니다. 다운샘플링은 잘 되어 있지만 읽기 단계에서 이미 원본 전체가 메모리에 올라옵니다. SecurityException(프로세스 종료 후 URI 권한 소멸), OutOfMemoryError 모두 잡히지 않습니다. CropActivity.saveCrop()의 FileOutputStream(...).use { compress(...) }도 IOException이 그대로 새어 나갑니다.
개선
디코딩과 저장을 Dispatchers.IO로 옮기고 실패 시 토스트로 되돌립니다.
// CropActivity.saveCrop()
lifecycleScope.launch {
    val cropped = binding.cropView.croppedBitmap() ?: return@launch reject()
    runCatching {
        withContext(Dispatchers.IO) {
            val dir = File(filesDir, "profile_photos").apply { mkdirs() }
            check(dir.isDirectory) { "저장 공간을 만들지 못했습니다" }
            File(dir, "profile_${System.currentTimeMillis()}.jpg").also { out ->
                FileOutputStream(out).use { cropped.compress(Bitmap.CompressFormat.JPEG, 92, it) }
            }
        }
    }.onSuccess { file ->
        cropped.recycle()
        setResult(RESULT_OK, intent.putExtra(EXTRA_RESULT_URI, Uri.fromFile(file).toString()))
        finish()
    }.onFailure {
        cropped.recycle()
        showBriefToast("사진을 저장하지 못했습니다")
    }
}
